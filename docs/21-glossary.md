# 21 — Glossar

| Begriff | Bedeutung im Projekt |
|---|---|
| Vaelith | Spieltitel und zugleich Name der nahezu allmächtigen magischen Entität der Geschichte |
| Oberwelt | Herkunfts-/Machtbereich, aus dem die Mutter des Spielers stammt; Kosmologie noch offen |
| Unterwelt | Herkunfts-/Machtbereich und Reich des Vaters des Spielers, des Unterweltkönigs |
| Science-Fantasy | Aktuelle Setting-Arbeitsrichtung: futuristische/technologische und magische/fantastische Elemente |
| Region | Inhaltlich/geografischer Weltbereich mit stabiler Identität |
| Chunk | Technischer Lade-/Renderabschnitt innerhalb der Welt |
| Biom | Ökologische/geografische Gebietsklassifikation |
| Gefahr | Risiko durch Kreaturen, Fraktionen, Umwelt oder Ereignisse; unabhängig vom Biom |
| Schwierigkeitsprofil | Einstufung/Skalierung der erwarteten Herausforderung |
| World Seed | Ausgangswert für reproduzierbare Generierung einer Welt |
| Region Seed | reproduzierbarer Ausgangswert einer Region |
| Generatorversion | Kennung der Regeln/Implementierung, mit denen Welt-/Regionsdaten erzeugt wurden |
| POI | Point of Interest: besonderer Ort wie Ruine, Dungeon, Höhle oder Landmarke |
| NPC | Non-Player Character, nicht vom Spieler gesteuerte Figur |
| Castle Build Mode | Spielerbau-/Gestaltungsmodus für Schloss und zugehörige Einrichtungen |
| Village Build Mode | Spielerbau-/Gestaltungsmodus für Dorf bzw. Siedlung |
| Vaelith Building Editor | Gemeinsames Editorfundament für Bauwerkzeuge und Bauprofile |
| Dungeon-Betrieb | Ausbau, Produktion, Verteidigung und Verwaltung eines befreiten Dungeons |
| Hoftiere | Eigene Kategorie besonderer Tier-/Lebewesenrollen; genaue Definition offen |
| MDP | VAELITH Modular Development Pipeline |
| Mod | Daten- oder Plugin-Erweiterung des Spiels |
| BepInEx | Vorgesehene technische Mod-Loader-Grundlage, Kompatibilität zu prüfen |
| Vaelith Mod API | Offizielle C#-Erweiterungsschnittstelle für Mods |
| Datenmod | Mod, die validierte Contentdaten ohne frei ausführbaren Plugin-Code ergänzt |
| Code-Mod | C#-Plugin, das im Prozess des Spiels läuft und als privilegierter Code behandelt werden muss |
| Quellenlücke | Benötigte Originalquelle liegt zur Prüfung nicht vor |
| Leitplanke | Im Projektgespräch klar formulierte Vorgabe |
| Arbeitskonzept | Ausgearbeitete Richtung, deren endgültige Bestätigung noch aussteht |
